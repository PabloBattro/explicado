Primer borrador para conversar

Un agente de ventas para Tabares

Una propuesta para atender consultas por WhatsApp, ayudar a elegir productos y llevar cada pedido hasta una confirmación clara, sin dejar a Manuel afuera de las decisiones sensibles.

Propuesta abierta · falta validar con Manuel

Qué problema resolvería

Hoy puede escribir un mayorista conocido, un comercio nuevo o alguien que quiere un solo mate. La idea es que todos reciban una respuesta rápida y que la conversación avance hacia una venta, sin prometer productos que no están disponibles ni perder el contexto cuando interviene una persona.

El primer alcance es deliberadamente chico: conversaciones de texto, catálogo, precios, stock, presupuesto por mail y pedido confirmado en Asana.

El recorrido propuesto

El agente acompaña la conversación. El cliente confirma. Manuel entra cuando hace falta criterio humano.

01MensajeUna persona escribe al WhatsApp de Tabares.
02ConocerEl agente pregunta lo necesario y distingue mayorista de minorista.
03AyudarResponde con catálogo, precios, fotos, detalles y stock disponible.
04ArmarPropone productos y cantidades hasta acordar un pedido.
05PresupuestarPide nombre y mail, y envía el presupuesto por correo.
06ConfirmarEspera una señal clara: “confirmo”, “dale” o “vamos adelante”.
07EntregarCrea automáticamente el pedido confirmado en Asana.

El agente acompaña. Manuel conserva el control.

No todo caso necesita una persona, pero siempre tiene que existir una salida clara hacia Manuel y una forma de devolver la conversación.

El agente

  • Atiende y califica a quien escribe.
  • Consulta el e-commerce y la base de stock.
  • Recomienda y busca cerrar el pedido.
  • Genera el presupuesto y reconoce una confirmación clara.
  • Crea el pedido confirmado en Asana.
⇄

Manuel

  • Recibe los casos que necesitan criterio o una excepción.
  • Toma la conversación sin competir con el agente.
  • Modifica manualmente pedidos que cambian por mail.
  • Devuelve el control cuando el caso queda resuelto.

Lo que ya está acordado

Entra cualquier cliente

El agente no parte de una lista cerrada: pregunta y califica durante la charla.

El stock se puede prometer

La disponibilidad que figura en la base es la referencia para vender.

El e-commerce sirve de apoyo

Fotos, descripciones y páginas de producto se pueden compartir durante la conversación.

El cliente confirma por mail

No alcanza el silencio: hace falta una respuesta que indique claramente que quiere avanzar.

Los cambios por mail son manuales

En el primer alcance, Manuel se ocupa de modificar un presupuesto ya enviado.

Solo se guardan datos necesarios

Para este flujo se definieron nombre y mail. Otros datos necesitan una decisión aparte.

Lo que necesitamos preguntarle a Manuel

Estas respuestas cierran el funcionamiento del negocio antes de decidir cómo construirlo.

Venta y precios

  1. ¿Qué datos distinguen a un mayorista y qué cambia para un minorista?
  2. ¿Hay un mínimo de unidades o monto para comprar al por mayor?
  3. ¿Cuál es la tabla exacta de descuentos por volumen? ¿Se aplica por producto o por pedido?
  4. ¿La base ya trae el precio final o el agente debe calcular descuentos?

Stock y fuentes

  1. ¿Con qué demora se actualiza el stock y qué pasa si dos clientes piden la última unidad?
  2. Si el e-commerce y la base muestran datos distintos, ¿cuál manda para precio, descripción y variantes?

Pedido y operación

  1. ¿Qué datos obligatorios debe incluir el presupuesto y qué necesita la tarea de Asana?
  2. ¿Cómo se acuerdan pago, factura, envío o retiro?
  3. ¿Qué respuesta recibe el cliente después de que el pedido entra en Asana?

Intervención de Manuel

  1. ¿Qué casos deben pasarle de inmediato?
  2. ¿Toma el control desde un panel o desde su propio WhatsApp?
  3. ¿Cómo se le avisa que hay una conversación esperando y cómo devuelve el control?
  4. ¿Qué se le dice al cliente cuando Manuel no está disponible?

Cómo sabremos si el primer alcance funciona

Antes de medir ventas reales, hay una prueba simple de punta a punta.

Una persona del equipo se hace pasar por cliente, conversa por WhatsApp, elige productos, recibe el presupuesto, confirma por mail y comprueba que el pedido correcto aparezca en Asana.

Este documento es una propuesta para validar. No describe todavía un sistema construido.
